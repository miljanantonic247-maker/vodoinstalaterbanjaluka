# Vodoinstalater Banja Luka — web sajt

Statički sajt (HTML/CSS/JS), spreman za hostovanje na GitHub Pages.

## Sadržaj
- `index.html` — cijeli sajt (jedna stranica)
- `assets/logo.png` — logo

## Objava na GitHub Pages
1. Napravi novi repozitorij na GitHubu (npr. `vodoinstalater-banja-luka`).
2. Ubaci `index.html` i folder `assets/` u korijen repozitorija (drag & drop na GitHub web, ili `git push`).
3. Settings -> Pages.
4. Build and deployment -> Source: "Deploy from a branch".
5. Branch: `main`, folder: `/ (root)` -> Save.
6. Za minut-dva sajt je živ na `https://<korisnicko-ime>.github.io/<ime-repozitorija>/`.

## Napomene
- Sekcije: Hero, Usluge, Kako radimo, O nama, Kontakt (sa ugrađenom Google mapom).
- Kontakt: poziv (tel), Viber; podaci se mijenjaju direktno u `index.html`.
- Tipografija: H1 32-48px, H2 24-32px, H3 20px, tekst 16px.
- Prije objave uskladi brojke "20+ godina" i "500+ radova" sa stvarnim podacima.
- Za vlastiti domen: Settings -> Pages -> Custom domain.
